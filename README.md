# SMS Sender — проста програма для Android

Завантажує список номерів телефонів з файлу `.txt` (один номер на рядок,
повний формат з кодом країни, наприклад `+48123456789`) і надсилає кожному
з них те саме SMS-повідомлення, по черзі, з паузою між повідомленнями.

Працює на пристрої з **однією SIM-карткою** — використовує стандартний
менеджер SMS системи Android. Не потребує статусу програми SMS за замовчуванням.

## Як зібрати .apk

Є два способи. Обидва використовують **лише офіційні інструменти Google/Gradle** — жодних сторонніх чи непідтверджених файлів.

### Спосіб А — без Android Studio, лише консоль (рекомендую)

Це буквально копіювання команд у термінал — жодного інтерфейсу розбирати не треба. Усе завантажується напряму з офіційних серверів Google/Gradle на вашому комп'ютері (ці сервери недоступні лише в моєму робочому середовищі, але не у вас).

**1. Встановіть Java (JDK 17)** — потрібна для Gradle:
   Завантажте й встановіть з https://adoptium.net (Temurin 17, LTS) — просто "Далі → Далі → Готово".

**2. Завантажте Android SDK Command-line Tools (офіційно від Google):**
   - Сторінка: https://developer.android.com/studio#command-tools — унизу сторінки розділ **"Command line tools only"**, файл `commandlinetools-win-*.zip`.
   - Розпакуйте так, щоб шлях виглядав саме так:
     `C:\android-sdk\cmdline-tools\latest\bin\sdkmanager.bat`
     (тобто вміст zip-архіву — папку `cmdline-tools` — покладіть у `C:\android-sdk\`, а те, що всередині неї, перемістіть/перейменуйте в підпапку `latest`).

**3. Відкрийте PowerShell і виконайте по черзі:**
   ```powershell
   $env:ANDROID_HOME = "C:\android-sdk"
   $env:Path += ";C:\android-sdk\cmdline-tools\latest\bin"

   sdkmanager --licenses
   ```
   На запити про прийняття ліцензій натискайте `y` і Enter.

   ```powershell
   sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
   ```

**4. Перейдіть у папку проєкту й запустіть збірку:**
   ```powershell
   cd шлях\до\sms-sender-android
   .\gradlew.bat assembleDebug
   ```
   Перший запуск сам довантажить Gradle 8.7 (кілька хвилин залежно від інтернету) — це нормально, більше такого не буде.

**5. Готовий файл з'явиться тут:**
   `app\build\outputs\apk\debug\app-debug.apk`

   Перекиньте цей файл на телефон (USB, пошта собі, Google Drive тощо) і встановіть — можливо, доведеться дозволити "Встановлення з невідомих джерел" у налаштуваннях Android.

### Спосіб Б — через Android Studio (якщо все ж зручніше з інтерфейсом)

1. Встановіть [Android Studio](https://developer.android.com/studio).
2. **File → Open** → виберіть папку `sms-sender-android`.
3. Дочекайтесь синхронізації Gradle.
4. Підключіть телефон (USB, режим розробника) або запустіть емулятор.
5. Натисніть зелену кнопку **Run ▶**.

Готовий `.apk` — там само: `app\build\outputs\apk\debug\app-debug.apk`.

## Формат файлу з номерами

Один номер на рядок, повний формат з кодом країни:

```
+48123456789
+48987654321
+48555111222
```

Порожні рядки ігноруються. Рядки, які не схожі на номер телефону (замало/забагато цифр, літери), пропускаються — після завантаження файлу програма покаже, скільки номерів пропущено.

## Важливі зауваження

- **Відповідність законодавству й правилам оператора**: масова розсилка SMS без згоди отримувачів може порушувати закони про захист даних/спам (GDPR тощо) і правила вашого оператора. Переконайтесь, що маєте правову підставу для контакту з кожним номером зі списку.
- **Системні обмеження/обмеження оператора**: Android і деякі оператори можуть обмежувати кількість SMS, надісланих за короткий час з однієї програми (захист від спаму). Типову паузу 1,5 секунди між повідомленнями можна змінити в програмі, але для дуже довгих списків варто спершу протестувати на меншій вибірці.
- **Вартість**: кожне SMS надсилається через вашу SIM-картку за звичайними тарифами оператора — програма не використовує жодного зовнішнього SMS-шлюзу.

## Структура проєкту

```
sms-sender-android/
├── gradlew, gradlew.bat         — офіційний Gradle wrapper (запускати збірку без встановленого Gradle)
├── gradle/wrapper/               — файли wrapper (gradle-wrapper.jar тощо)
├── build.gradle                  — конфігурація всього проєкту
├── settings.gradle
├── gradle.properties
└── app/
    ├── build.gradle              — залежності (AndroidX, coroutines тощо)
    └── src/main/
        ├── AndroidManifest.xml   — дозвіл SEND_SMS
        ├── java/com/example/smssender/
        │   └── MainActivity.kt   — уся логіка програми
        └── res/
            ├── layout/activity_main.xml
            ├── values/strings.xml
            ├── values/themes.xml
            └── drawable/ic_launcher.xml
```

## Що легко доопрацювати пізніше

- Dual-SIM (вибір SIM-картки для відправки) — якщо все ж знадобиться.
- Персоналізація повідомлення (наприклад, `{номер}` у тексті).
- Збереження звіту розсилки (який номер вдався/не вдався) у файл.
- Читання номерів з CSV/Excel замість чистого `.txt`.
